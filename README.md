# 🍎 AppleCheck — Identificación de manzanas

Frontend estático para analizar fotografías de manzanas y mostrar una estimación visual de **buen estado**, **mal estado** o **resultado incierto**.

## Ejecutar
Abre `index.html` en un navegador.

## GitHub Pages
El repositorio incluye un workflow en `.github/workflows/pages.yml` que publica el contenido de `main` en GitHub Pages después de cada push.

> Nota: la clasificación incluida es una demostración visual en el navegador. Para un modelo de IA entrenado específicamente con `project.tm`, hay que exportar el modelo de Teachable Machine y añadir sus archivos al sitio.
